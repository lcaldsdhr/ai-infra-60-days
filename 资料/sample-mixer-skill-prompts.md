# Sample Mixer 实现检索与代码复用提示词

按顺序分两轮使用：第一轮安装必要 skills，第二轮调用 skills 完成实现检索与复用分析。

## 第一轮：安装必备 skills

复制以下提示词到聊天中执行：

```text
$skill-installer

请安装以下两个 skill：

1. huggingface-papers
   仓库：huggingface/skills
   路径：skills/huggingface-papers

2. paper-lookup
   仓库：K-Dense-AI/claude-scientific-skills
   路径：skills/paper-lookup

如果已安装则保留。检查 SKILL.md 和必要配套文件是否齐全，
简要报告安装结果、必要依赖和可用状态。
```

## 第二轮：寻找 Sample Mixer 的可复用实现

安装完成后，在下一轮聊天中复制以下提示词：

```text
$huggingface-papers
$paper-lookup

请使用上述 skills，重新调研 MiMo-V2.6 论文中 Sample Mixer
的官方实现、参考文献对应代码，以及功能相近的可复用实现。

论文：https://arxiv.org/abs/2610.11959
重点：§6.3 Sample Mixer，以及相关引用。

目标是为“Sample Mixer 综合开发与验收计划”提供源码复用依据，
任务范围为检索、源码核对和复用建议。

一、寻找实现

1. 官方代码
从论文、作者项目页和官方组织仓库确认实现入口。
区分完整实现、部分实现和复现实验代码。
没找到时说明查过哪些范围，不直接断言没有开源。

2. 引用链代码
沿 Sample Mixer 相关引用，寻找 dynamic sampling、
partial rollout、异步调度等方法的原始论文和作者实现。
核对引用关系，不把功能相近的项目当成论文引用。

3. 相近实现
补充具有以下能力的代码：
- 按来源维护目标配额和接受率；
- 自适应并发预算；
- 基于目标与当前缺口的来源调度；
- 考虑 KV 容量、负载和轨迹长度的派发；
- 样本重放、过期控制、启动和恢复。

二、核对源码

对每个推荐候选，打开实际源码，确认：
- 仓库、分支或 commit；
- 具体文件、类或函数；
- 实际实现的能力；
- 与 MiMo 方案的差异和缺失部分；
- 接入依赖、许可证和迁移成本。

特别区分：
- prompt group 与单条 trajectory；
- 过滤后补采与多来源配额平衡；
- 未完成轨迹续跑与已完成轨迹重放；
- 全局并发控制与按来源自适应预算。

README 声明不能替代源码核对。
仅阅读过的代码标为“源码已核对”；实际运行过才能标为“已验证”。

三、输出

先给简短结论，再列出最值得借鉴的 3–5 个候选：

项目 | 来源关系 | 文件/函数链接 | 可复用能力 |
缺失部分 | 接入成本 | 验证状态

最后提供：
1. 四个 Sample Mixer 组件分别建议参考什么；
2. 哪些可以直接复用、哪些需要适配、哪些需要自行实现；
3. 一段可直接加入“综合开发与验收计划”的精简建议。

控制篇幅，优先给具体源码入口和复用判断。
```
